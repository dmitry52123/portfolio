# Портфолио: Python-разработка

Telegram-боты, парсеры и автоматизация на Python. Каждый проект — рабочий код с тестами и автоматическими проверками качества.

| Проект | Что делает | Стек |
|---|---|---|
| [💈 Бот записи клиентов](booking-bot/) | Запись в салон/барбершоп: свободное время, напоминания, отмена, панель администратора | aiogram 3, SQLite, Docker |

## Как я проверяю код
Каждый проект при каждом изменении автоматически проходит проверки на серверах GitHub (вкладка **Actions**):
- **pytest** — автотесты, включая сквозные сценарии;
- **ruff** — ошибки и стиль кода;
- **mypy** — строгая проверка типов;
- **bandit** — проверка безопасности.

## Чем могу помочь
- Telegram-боты: запись, заявки, рассылки, оплата, админ-панели
- Парсинг сайтов и мониторинг цен с выгрузкой в Excel / Google Таблицы
- Автоматизация рутинных задач, интеграции с API
- Исправление и доработка существующих скриптов
