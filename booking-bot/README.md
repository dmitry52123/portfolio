# 💈 Telegram-бот записи клиентов

Бот для салона, барбершопа или любого мастера: клиент сам выбирает услугу, день и свободное время,
оставляет имя и телефон — мастер сразу получает уведомление. Без звонков и переписок.

## Возможности

**Для клиента**
- выбор услуги с ценой и длительностью;
- календарь на 7 дней вперёд и **только реально свободное время** — с учётом длительности услуги, уже занятых записей и времени закрытия;
- имя и телефон (кнопкой «Отправить мой номер» или вручную, номер проверяется и приводится к виду +7XXXXXXXXXX);
- подтверждение записи и **напоминание за 2 часа** до визита;
- «Мои записи» — просмотр и отмена своих записей;
- контакты и часы работы.

**Для администратора**
- уведомление о каждой новой записи и отмене;
- команда `/admin` — расписание на неделю;
- отмена любой записи кнопкой (клиент получает сообщение).

**Надёжность**
- **двойная запись на одно время невозможна** — даже если два клиента подтверждают одновременно (проверено тестом на 20 одновременных запросов);
- нельзя отменить чужую запись, админка доступна только администраторам;
- все тексты от пользователей экранируются (защита от HTML-инъекций в сообщениях);
- время хранится в UTC, показывается в часовом поясе салона.

## Стек
Python 3.12 · aiogram 3 · SQLite · asyncio · Docker

## Качество кода
| Проверка | Инструмент | Результат |
|---|---|---|
| Тесты (логика, база, сквозные сценарии в Telegram) | pytest | 37 тестов |
| Линтер и стиль | ruff | без замечаний |
| Строгая проверка типов | mypy --strict | без ошибок |
| Безопасность | bandit | без замечаний |

Сквозные тесты имитируют реального клиента: `/start` → услуга → день → время → имя → телефон → подтверждение,
плюс отмена, админ-панель, напоминания и попытка занять уже занятое время.

## Запуск

```bash
git clone <этот репозиторий> && cd booking-bot
cp .env.example .env        # вписать BOT_TOKEN от @BotFather и свой ADMIN_IDS
pip install -r requirements.txt
python -m bot.main
```

Через Docker:
```bash
docker build -t booking-bot .
docker run -d --restart=always --env-file .env -v booking-data:/data booking-bot
```

Проверки разработчика:
```bash
pip install -r requirements-dev.txt
pytest && ruff check . && mypy bot tests && bandit -r bot
```

## Настройка под салон
Услуги, цены и длительность — в `bot/config.py` (`SERVICES`). Название, адрес, телефон, часы работы и часовой пояс — в `.env`.

## Структура
```
bot/
  main.py          точка входа, сборка диспетчера, фоновые напоминания
  config.py        настройки и список услуг
  services.py      бизнес-логика: свободные слоты, проверка телефона и имени
  db.py            SQLite: записи, защита от двойной записи
  keyboards.py     кнопки
  reminders.py     напоминания перед визитом
  handlers/
    client.py      сценарий клиента
    admin.py       панель администратора
tests/             unit-тесты и сквозные тесты сценариев
```
