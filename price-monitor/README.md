# 📉 Мониторинг цен: парсер + Excel + Telegram

Собирает товары из каталога интернет-магазина, сохраняет историю цен и **присылает в Telegram,
когда что-то подешевело, подорожало, закончилось или вернулось в наличие**. Всё выгружается в Excel.

Демо работает на [books.toscrape.com](https://books.toscrape.com) — открытом сайте для практики парсинга.
Под другой магазин меняется один модуль разбора страниц (`monitor/parse.py`).

## Что умеет
- обход всего каталога по страницам (ссылка «следующая»), с ограничением числа страниц и защитой от зацикливания;
- название, цена, валюта, наличие, рейтинг, ссылка;
- **история цен** в SQLite и сравнение с прошлым запуском:
  📉 подешевело · 📈 подорожало · ❌ закончился · ✅ снова в наличии · 🆕 новый товар;
- фильтр «шума»: можно не сообщать об изменениях меньше N %;
- **Excel**: лист «Товары» (фильтры, закреплённая шапка, кликабельные ссылки) и лист «Изменения»;
- уведомления в **Telegram**, длинные списки автоматически делятся на сообщения в пределах лимита;
- работа по расписанию (`--every 60` — каждый час) или разовым запуском.

**Надёжность**
- повтор запроса при временных сбоях (429, 5xx, обрыв сети) с нарастающей паузой; на 404 — сразу ошибка;
- вежливая пауза между страницами и понятный User-Agent;
- цены в `Decimal` — без ошибок округления;
- первый запуск — «стартовый снимок» без спама на 1000 уведомлений;
- если вёрстка сайта изменилась — понятная ошибка, а не тихо пустой отчёт;
- названия товаров экранируются в сообщениях (защита от HTML-инъекций).

## Результат на живом сайте
1000 товаров с 50 страниц за ~30 секунд, без дублей; повторный запуск — 0 ложных изменений.

## Стек
Python 3.12 · httpx · BeautifulSoup + lxml · SQLite · openpyxl · Docker

## Запуск
```bash
cp .env.example .env              # при желании вписать TELEGRAM_BOT_TOKEN и TELEGRAM_CHAT_ID
pip install -r requirements.txt
python -m monitor.cli             # один раз: prices.xlsx + prices.db
python -m monitor.cli --every 60  # каждый час
```
Параметры: `--pages 5` (сколько страниц), `--min-change 2` (игнорировать изменения меньше 2 %), `--url`, `--db`, `--excel`.

Через Docker (каждый час, данные в томе):
```bash
docker build -t price-monitor .
docker run -d --restart=always --env-file .env -v prices-data:/data price-monitor
```

## Структура
```
monitor/
  parse.py    разбор страниц каталога (меняется под конкретный сайт)
  fetch.py    загрузка: таймауты, повторы, паузы, обход страниц
  storage.py  SQLite: текущие цены, история, поиск изменений
  export.py   Excel
  notify.py   сообщения в Telegram
  cli.py      запуск и расписание
tests/        тесты; fixtures/ — реальные страницы сайта
```
